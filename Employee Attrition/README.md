# HR Employee Attrition Analysis

## Objective
Analyzed IBM HR dataset to identify key drivers of employee attrition 
and built an interactive dashboard for HR decision-making.

## Tools Used
Python (Pandas, Seaborn, Matplotlib) | SQL (MySQL) | Power BI

## Key Findings
- Overall attrition rate: 16%
- Sales department has highest attrition at 20.6%
- Employees earning below ₹5000/month are 2x more likely to leave
- Employees aged under 30 show significantly higher attrition
